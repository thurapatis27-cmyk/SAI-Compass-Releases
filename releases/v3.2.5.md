## Changes

- Add Transaction (Expense) now uses a single typed **“Type your expense”**
  input with a live offline icon preview, replacing the manual expense
  category picker.
- The Note field was removed from the Add Transaction form. Existing stored
  notes remain readable and are preserved when editing older records.
- Added comprehensive offline item recognition and icon mapping for everyday
  groceries, vegetables, fruits, household items, bills, transport, health,
  education, shopping, and more, including English, Telugu, and Hindi aliases.
- Matching handles exact words, normalized case/spacing, multi-word phrases,
  singular/plural forms, synonyms, common spelling variants, and safe
  whole-word keyword fallbacks. Unknown items use a neutral general-purpose
  item icon; no dollar/money symbol is used as the universal fallback.
- Each new or edited expense stores its typed `description` and a stable
  `iconKey`; transaction history shows the typed description and persisted
  icon. Older rows keep resolving through their existing category, note, or
  custom name without migration.
- Expense category is inferred from the typed item so reports, filters, and
  insights continue to work. Totally unrecognized items fall back to
  `other_expense`.
- Untouched historical expense edits preserve their original category,
  custom name, and note. Income still keeps its category picker.
- No database schema or Dexie version change; record IDs, loan numbers,
  accounting relationships, and user data were not modified.
